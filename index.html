1. Overview

Snabby is a browser extension designed for high-resolution web screenshot capture, interactive crop region selections, local offline Optical Character Recognition (OCR), and searchable PDF document generation.

We believe that your private data should remain private. Snabby is built from the ground up to operate completely offline. There are no backend servers, no analytics platforms, and no tracking scripts. All data processing, OCR text extraction, PDF compilation, and file storage occur locally on your device inside your web browser.

2. Information Snabby Processes

Snabby only accesses and processes information when you explicitly interact with the extension's features. The processed data categories are:

  • Captured Webpage Content: Raw visual screenshots of the webpage viewports or cropped regions that you select. These visual captures may contain webpage text, layouts, images, and other visible elements.
  • OCR Extraction Data: Locally extracted text layers and word-level coordinate bounding boxes derived from the captured images.
  • Session Metadata: User-provided session names, timestamps, and order indexes used to organize multiple captures within a current session.
  • User Settings: Your configured extension settings (such as visible viewport capture vs. crop region capture mode).
No Browsing History Collection
Snabby does not monitor, collect, or store your web browsing history. It only accesses webpage content on active tabs when you explicitly trigger a screenshot capture (via the toolbar UI or keyboard shortcuts).

3. How We Use Data

Snabby processes your data solely to deliver its core features. This includes:

  • Rendering captured screenshots inside Snabby's React UI panel so you can review, sort, or delete them.
  • Running offline OCR text extraction on your captured screenshots.
  • Mapping OCR coordinate structures to place invisible, searchable text layers precisely over the visual screenshots inside the output PDF.
  • Compiling your session captures locally into a final, downloadable PDF.

4. Local Processing and Storage

Snabby runs completely in your browser context and does not communicate with external backend services.

All captured images (Blobs), session metadata, capture details, and OCR results are persisted locally on your computer inside your browser's isolated IndexedDB database (named snabby). Your selected settings are stored locally in Chrome's extension-isolated storage (chrome.storage.local).

No data is uploaded to remote servers or shared with any third party.

5. OCR Processing

Optical Character Recognition (OCR) is performed entirely inside the local browser application using an isolated background environment.

When a screenshot is captured, Snabby's background Service Worker coordinates with an isolated Chrome Offscreen Document to initialize Tesseract.js. The Tesseract worker script, WASM engine, and English language training data (eng.traineddata) are all loaded directly from the local extension package. Text extraction is completed offline, and the resulting coordinates and text are written directly to your local IndexedDB.

6. PDF Generation

Searchable PDF generation is performed locally. Snabby uses the pdf-lib library to process your screenshot image files and combine them with the corresponding OCR coordinate records in memory.

The final PDF document is constructed by drawing the visual image layer and laying the matching text structure over it at 0% opacity (making it invisible but selectable). The document download is then initiated locally through Chrome's Downloads API. No document compilation takes place on external servers.

7. Data Sharing

Snabby maintains a strict stance on data isolation:

  • We do not operate any backend servers; there is no pipeline to receive or store your data.
  • We do not sell, rent, or trade your data or captured content with third parties.
  • We do not track you. Snabby does not contain analytics platforms, telemetry reporters, or profiling tools.
  • We do not use your captured content for advertising, marketing, or tracking.

8. Data Retention and Deletion

You have complete control over the lifecycle of your local data:

  • Manual Capture Deletion: Deleting a single capture from the session grid permanently deletes the capture record, its associated visual screenshot image, and the extracted OCR result from your local IndexedDB database.
  • Session Deletion: Clicking "End Session" or completing a PDF download automatically terminates the session. This executes a cascade delete transaction that wipes the session record, all related captures, all visual images, and all OCR results from the database.
  • Extension Uninstallation: Uninstalling Snabby from your browser forces Google Chrome to delete the extension's entire storage partition, including all configuration files and the IndexedDB database.

9. Browser Permissions

Snabby requests specific browser permissions to operate. These permissions and their technical purposes are detailed below:

Permission Purpose
activeTab Allows the extension to capture a visual screenshot of the current tab's viewport when you trigger a capture.
scripting Used to inject the crop overlay interface and React panel into target webpages.
offscreen Allows Snabby to create an Offscreen Document to initialize and run Tesseract.js (which requires DOM/Window objects unavailable in service workers).
storage Allows the extension to save configuration preferences (such as visible capture vs. crop region mode) locally in the browser.
unlimitedStorage Ensures Chrome does not block or throttle Snabby from saving high-resolution screenshots and OCR layers locally in your IndexedDB database.
tabs Used to query tab states, check URLs, and communicate layout changes across multiple tabs.
downloads Allows the extension to trigger the download prompt to save the compiled searchable PDF directly to your device.
<all_urls> (Host Permission) Necessary to allow Snabby's capture and panel injection utilities to run on any webpage you choose to capture.

10. Security

By designing Snabby to operate entirely offline, the risk of interception or server-side data breaches is eliminated. The data is secured using the browser's sandbox and origin boundary controls, ensuring that other extensions and websites cannot access Snabby's IndexedDB stores.
